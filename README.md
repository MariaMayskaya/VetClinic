# Ветеринарная клиника: Информационная система управления


**Курсовой проект** по автоматизации деятельности ветеринарной клиники.
Приложение (Desktop), разработанное на C# и Windows Forms. Система позволяет автоматизировать ключевые бизнес-процессы: ведение клиентской базы, запись на прием, создание электронных медицинских карт животных и управление аптечным складом.

## 📋 Основные возможности

Система реализует два основных сценария работы в зависимости от роли пользователя:

### 👤 Для клиента (владельца животного)
*   **Регистрация и вход** с защитой капчей.
*   **Управление питомцами**: добавление, просмотр списка своих животных.
*   **Запись на прием**: выбор питомца, удобной даты и свободного времени (слоты с 8:00 до 20:00). Автоматическая проверка на занятость.
*   **Просмотр истории болезней**: детальная информация о диагнозах, лечении и назначениях для каждого питомца.

### 🛡️ Для администратора (дополнительные функции)
*   **Централизованное управление**: просмотр всех пользователей, питомцев и записей.
*   **Управление записями**: фильтрация по статусу (Запланирован, Завершен, Отменен), изменение статуса.
*   **Ведение медицинских записей**: создание электронных карт с диагнозом, лечением и назначениями.
*   **Управление аптекой**:
    *   Полный CRUD для лекарств (добавление, редактирование, удаление).
    *   Контроль остатков и сроков годности.
    *   Визуальная индикация низкого запаса (менее 10 шт.) и просроченных препаратов.
    *   Поиск по названию и описанию.

## 🛠️ Используемые технологии

*   **Язык программирования:** C#
*   **Платформа:** .NET Framework 4.8
*   **UI-фреймворк:** Windows Forms (с кастомной отрисовкой для скругленных углов и визуальных эффектов)
*   **База данных:** SQLite (файловая, не требует установки сервера)
*   **Безопасность:** BCrypt.Net-Next (хеширование паролей)

## 🚀 Как начать работу

### Требования
*   Операционная система: Windows 7 и выше.
*   Установленный .NET Framework 4.8 или выше (обычно уже есть в Windows 10/11).
